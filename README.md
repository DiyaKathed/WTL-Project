



# Rushi Krushi Seva Kendra

## Project Description

Rushi Krushi Seva Kendra is a farmer-focused web portal designed to provide
agricultural product information, crop-related information, and basic farmer
support services through a simple and responsive web interface.

The website is designed for a Krushi Seva Kendra and provides farmers with
easy access to information about agricultural products, crops, farming
guidance, and support services.

The project is developed progressively in three stages:

- Task 1 — HTML5 + CSS3
- Task 2 — JavaScript + DOM
- Task 3 — PHP + File Upload

---

## Main Features

The portal provides:

- Home / Landing Page
- About Krushi Seva Kendra
- Seeds Information
- Fertilizers Information
- Pesticides Information
- Agricultural Tools Information
- Spray Pumps Information
- Crop Information
- Kharif Crop Information
- Rabi Crop Information
- Crop Calendar
- Farmer Support
- Farmer Helpline
- Farmer Registration
- FAQ Section
- Contact Information
- Farmer Photo Upload
- ID Proof Upload
- Admin Management Interface

---

# Website Structure

The website is divided into separate sections and pages so that farmers
can easily navigate to the information they require.

## Main Navigation

- Home
- About
- Products
- Farmer Information
- Farmer Support
- Contact
- Login

---

## Product Information

The Products section provides separate pages for different agricultural
products.

Products include:

- Seeds
- Fertilizers
- Pesticides
- Agricultural Tools
- Spray Pumps

Each category can contain product details, descriptions, images, and
other relevant information.

---

## Farmer Information

The Farmer Information section is designed as an agricultural information
hub.

It includes:

- Crop Information
- Kharif Crops
- Rabi Crops
- Crop Calendar
- Seasonal Farming Information
- General Farming Guidance

Individual crop pages can provide information such as:

- Crop overview
- Growing season
- Soil and climate requirements
- General cultivation information
- Common crop problems
- Farmer support

---

## Farmer Support

The Farmer Support section allows farmers to submit their queries and
seek general agricultural assistance.

The support form includes fields such as:

- Farmer Name
- Mobile Number
- Village
- Crop
- Problem Category
- Problem Description
